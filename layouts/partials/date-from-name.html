改写成【拷贝时间】 后者的表现很有迷惑性 —— EXIF 里确实有值，但整批照片的时间戳 一模一样（都是拷贝那一刻），按它归档会把所有照片堆到同一天。 而手机相机的文件名本身就编码了拍摄时间，且不会被传输工具改动： IMG_20260801_212545.jpg → 2026-08-01 21:25:45 (安卓相机) mmexport1778327064654.jpg → 2026-05-09 19:44:24 (微信，毫秒时间戳) Screenshot_2026-08-01-21-25-45.png 20260801_212545.jpg 2026-08-01-xxx.jpg https://cdn.example.com/2026/08/01/AbCdEf.jpg (图床按日期分目录) ── noTimestamp 是干什么的 ── 最后那条 13 位毫秒时间戳规则只认「数字串」，不认上下文。本地文件名 是作者手写的，误判概率可以接受；但图床 URL 里的 13 位数字串更可能 是 CDN 的哈希/ID —— 实测 https://i.imgur.com/AbC1234567890123.jpg 会被解析成 2009-02-14，一个看着挺合理、其实完全错误的日期 （13 位随机数约有 1/3 落进 1990–2100 这个年份守卫里）。 所以远程图床传 noTimestamp=true 关掉这条规则。代价是微信导出名 （mmexport<13位>）放到图床上的话认不出来，那种情况写显式 date 即可。 ── 时区 ── 前几类模式解析出的是「墙上时间」，不带时区，直接按原值格式化即可， 不做换算。毫秒时间戳是绝对时刻，按站点时区解读，避免跨日偏移。 */ -}} {{- $name := . -}} {{- $noTs := false -}} {{- if reflect.IsMap . -}} {{- $name = .name -}} {{- $noTs = .noTimestamp | default false -}} {{- end -}} {{- if not $name -}} {{- return false -}} {{- end -}} {{- $loc := site.Params.timeZone | default "Asia/Shanghai" -}} {{- $s := "" -}} {{/* 1) YYYYMMDD_HHMMSS —— 安卓相机直出：IMG_20260801_212545.jpg */}} {{- with findRE `(?:19|20)\d{6}[_-]\d{6}` $name 1 -}} {{- $v := index . 0 -}} {{- $s = printf "%s-%s-%sT%s:%s:%s" (substr $v 0 4) (substr $v 4 2) (substr $v 6 2) (substr $v 9 2) (substr $v 11 2) (substr $v 13 2) -}} {{- end -}} {{/* 2) YYYYMMDDHHMMSS —— 同样 14 位但不带分隔符 */}} {{- if not $s -}} {{- with findRE `(?:19|20)\d{12}` $name 1 -}} {{- $v := index . 0 -}} {{- $s = printf "%s-%s-%sT%s:%s:%s" (substr $v 0 4) (substr $v 4 2) (substr $v 6 2) (substr $v 8 2) (substr $v 10 2) (substr $v 12 2) -}} {{- end -}} {{- end -}} {{/* 3) YYYY-MM-DD 或 YYYY_MM_DD */}} {{- if not $s -}} {{- with findRE `(?:19|20)\d{2}[-_]\d{2}[-_]\d{2}` $name 1 -}} {{- $v := index . 0 -}} {{- $s = printf "%s-%s-%sT12:00:00" (substr $v 0 4) (substr $v 5 2) (substr $v 8 2) -}} {{- end -}} {{- end -}} {{/* 3b) YYYY/MM/DD —— 图床按日期分目录：cdn.example.com/2026/08/01/AbCdEf.jpg 这种 URL 的 basename 远程图床用 noTimestamp 关掉它，理由见文件头。 */}} {{- if not $noTs -}} {{- $ms := $name | replaceRE `^.*?(?:^|\D)(\d{13})(?:\D|$).*$` "$1" -}} {{- if ne $ms $name -}} {{- $t := time.AsTime (div (int $ms) 1000) $loc -}} {{- $y := $t.Year -}} {{- if and (ge $y 1990) (le $y 2100) -}} {{- return $t -}} {{- end -}} {{- end -}} {{- end -}} {{- return false -}}
